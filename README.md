# N.E.D-Hub

Web3 Admin Dashboard & Infrastructure Control Panel for N.E.D Wallet on Solana.

## Project Structure

- `ned-hub/`: Next.js 16 (Turbopack + Tailwind CSS v4) Web3 Dashboard application.

## Vercel Deployment Configuration

- **Root Directory**: `ned-hub`
- **Framework Preset**: Next.js
- **Build Command**: `pnpm run build`
